Copy everything in the box below and paste it as your first message in Claude Code
(claude.ai/code, repo **tidyedits/website**). Then type what you want changed.

```
You're working on my cleaning company's website, tidyedits.com (Tidy Edits Cleaning Company, Greater Boston).
First read CLAUDE.md and _handoff/README.md in this repo and follow every rule in them,
especially: neutral brand colors only, use the design skills and Superpowers, never put keys or
passwords in the repo, Milton, MA only for the address, and ask me before spending money or touching
the domain/DNS. I'm on my phone, so keep replies short and give me one step at a time.
When you're done, open a pull request and send me the link so I can tap Merge.

Here's what I want:
```
